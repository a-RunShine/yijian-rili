# v1.6.0 - 三段壳主界面 + 周末总结 + 自定义间隔

## 新增

- 🎛️ **主界面三段壳**：顶部改为「创建 / 日程 / 设置」分段切换。日历账户、复习间隔、窗口设置这些低频项全部移进「设置」段，创建第一屏只留标题 → 日期 → 预览 → 写入。
- 📝 **详情输入区**：新增「详情」输入框（可选），写一次备注，会同步写进该复习系列全部日程的备注。
- ➕ **自定义复习间隔**：可动态增减间隔数量（最多 10 个），严格递增校验（必须大于前一个，取值 1~365），并支持「保存为预设」复用常用方案、删除自定义预设。
- 🗑️ **搜索里删除日程**：搜索结果列表与详情页都有垃圾桶入口，删除前二次确认；复习计划还可以整组打开、逐条勾选要删的复习，一次删掉。
- 📅 **周末总结**：按周浏览学习条目，逐条标记「已复习 / 未复习」，底部写本周总结（自动保存）；可翻上一周 / 下一周并一键回到本周。
- 🕘 **今日所建**：「日程」段顶部列出今天创建的复习批次（标题 · 基准日期 · 模式 · 创建时间），每行可编辑系列共享详情，一次改动同步写入该系列全部日程。

## 改进

- 🎨 **分段选择器动画**：顶部选中段用 spring 动画在两段之间滑动切换。
- 🗂️ **次要设置可折叠**：日历账户 / 复习间隔 / 窗口设置三个区可折叠，展开状态跨重启记忆；窗口设置折叠头直接显示「置顶 / 普通」。
- 🖱️ **操作区上移并固定**：主操作区移到输入流之后并固定在底部 Footer；点「再建一个」自动滚回标题输入框。
- 🐛 **周末总结统计修正**：「预占位」条目改标为「上周周末创建」，且不再计入当周已复习进度。
- 🎨 **搜索详情更紧凑**：搜索结果详情改为 slide 动画 + 紧凑布局；历史区标注「最多 20 条 · 与周末总结分离」。
- 📖 **升级自动迁移**：升级到本版本后，历史学习记录会自动迁入周末总结，无需手动操作。

## 下载

下载 `YijianRili-v1.6.0-macOS.app.zip`，解压后把 `一键日历.app` 拖到「应用程序」文件夹即可。
也可以下载 `.dmg` 镜像获得更顺手的安装体验。

## 系统要求

macOS 14.0+，首次使用会请求日历权限。
