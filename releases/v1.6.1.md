# v1.6.1 - 系列生命周期：对账、改标题、完成态、日程系列化

## 新增

- 🔄 **静默对账**：刷新日程 / 搜索 / 今日所建时，自动修剪日历里已不存在的复习事件 id；整批都没了则清掉历史与周末总结对应条目。
- ✏️ **整系列改标题**：在系列共享详情之外，可一次改写该系列仍存在成员的标题，并同步历史与周末总结展示。
- 🏷️ **日程列表系列感知**：昨 / 今 / 明卡片对复习系列显示系列标识，编辑与选择性删除与搜索同构。
- ✅ **复习完成态**：可对系列 occurrence 标记「完成 / 跳过」，持久化后在周末总结「本周复习进度」展示；不占用创建条目级「已复习」勾选（F6）。

## 改进

- 对账与应用内选择性删除共用同一套「剩 id / 丢整批」规则。
- 空系列标题仍可只保存共享详情；联合保存时标题结果反馈可见。

## 下载

下载 `YijianRili-v1.6.1-macOS.app.zip`，解压后把 `一键日历.app` 拖到「应用程序」文件夹即可。
也可以下载 `.dmg` 镜像获得更顺手的安装体验。

## 系统要求

macOS 14.0+，首次使用会请求日历权限。
