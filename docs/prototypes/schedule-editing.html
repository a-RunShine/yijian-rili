删除日程时，怎么找到那条日程

这个原型只回答一个问题：「删不掉」到底该算失败，还是该算「本来就不在了」？ 把定位方式从「事件 id」换成「系列 + 第几次复习 + 日期 + 标题 + 备注」之后， 用户看到的那条假失败会不会消失。

下面右侧的「记录」是应用自己存的历史，左侧是系统日历里真实存在的日程。 两侧会不一致——按 id 找和按内容找，对这份不一致的反应完全不同。
