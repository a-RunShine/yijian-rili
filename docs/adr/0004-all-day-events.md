# 0004 创建全天日程而非定时日程

- **状态**：已采纳
- **日期**：2026-10-20（迁入本目录）
- **来源**：`openspec/changes/one-click-calendar/design.md` 第 4 节

## 决策

复习提醒写成全天日程（all-day event），不带具体时刻。

## 背景

复习提醒需要出现在某一天。可以选一个具体时刻（如早上 9 点），也可以做成全天事件。

## 理由

- 复习不需要精确到时刻——用户当天任意时间做都行，钉死时间反而制造压力
- 全天日程在 Calendar.app 里固定在顶部，比埋在时间轴里更容易被看到
- 免掉时区与时刻设置的一整类复杂度：跨时区旅行、夏令时切换都不影响「哪一天」
- 全天日程本身就有提醒效果，不需要额外配置闹钟

## 替代方案

**定时日程**（如每天早上 9:00）：更具体，但引入了不必要的复杂度，且与「复习随时可做」的语义不符。

## 后续影响

- 复习日计算全部基于日历日，不涉及时刻
- 重复检测按「标题 + 日历日 + 规范化复习备注键」比对，不比较时刻
- 界面上的日程列表需要区分全天与定时事件（来自其他应用的事件可能是定时的）
