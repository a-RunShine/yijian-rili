# 0005 允许重复创建但给出警告

- **状态**：已采纳
- **日期**：2026-10-20（迁入本目录）
- **来源**：`openspec/changes/one-click-calendar/design.md` 第 5 节

## 决策

同名同日的复习日程**不阻止**创建，但向用户显示警告。

## 背景

用户重复输入相同标题、相同基准日时，会产生一批重复日程。

## 理由

- 用户可能确实需要在同一天复习多个主题，标题相同不代表内容相同
- 直接阻止会中断用户流程，把「我确定要建」变成一次额外确认
- 警告给了知情权，但把最终决定权留给用户——这是本项目一贯的取舍方向

## 替代方案

**完全阻止重复**：过于严格，会误伤正常需求，且无法区分「手滑重复」与「有意重复」。

## 后续影响

- 重复检测的判定必须是**稳定**的：按标题 + 日历日 + 规范化后的复习备注键比对。备注键的规范化规则见 `GLOSSARY.md` 的「复习备注键」与「备注详情提取」
- 结果提示需要区分「成功 / 部分成功 / 警告」三态。部分写入（有些复习日成功、有些撞重）也必须可撤销
- 「警告但不阻止」意味着警告文案要能说清哪些天重叠，而不只是弹一句「已存在」
